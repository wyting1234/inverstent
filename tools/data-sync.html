4合并规则与安全说明

「下载并合并」怎么判断冲突

本页会记住上次同步时的数据指纹，因此能分辨「只有一方改过」和「两边都改过」：

只有本机改过直接保留本机
只有云端改过采用云端
两边都改过（列表）按记录 id 取并集；同一条记录比 updatedAt，较新者胜，平局保留本机
两边都改过（对象）逐字段合并，同一字段冲突时保留本机
两边都改过（普通值）保留本机
仅一方存在该键有的一方胜出（不会因为另一端没这个键就删掉）

所以合并只会让数据变多，不会让记录凭空消失；同一条记录被两台设备改过时，才会发生「一边覆盖另一边」，此时以时间较新的为准。

多设备怎么用

  • 各设备打开同一个网址，填入同一个令牌 + 同一个仓库名 + 同一个空间名；
  • 都点一次「下载并合并」，数据即对齐；
  • 之后每次换设备前在旧设备点「上传」，在新设备点「下载并合并」；
  • 本页打开时会自动比对云端时间，发现云端更新会顶部提示（只提示，不自动覆盖）。

安全

  • 令牌保存在本机浏览器的 localStorage，页面源码中不含任何令牌；
  • 数据写入你的 Gitee 私有仓库，只有持令牌者能读；
  • 换机器或怀疑令牌泄露，点「清除本机配置」，并到 Gitee 后台吊销该令牌；
  • 云端文件名形如 data-default.json，改「同步空间」名即可隔离出多套互不干扰的数据。

说明

  • 本站页面同源，所以本页能读写其它工具的数据；但同步后请到对应页面刷新一次，界面才会显示新数据。
  • 「下载并覆盖本机」与「删除云端备份」是不可逆操作，都会先弹确认。
